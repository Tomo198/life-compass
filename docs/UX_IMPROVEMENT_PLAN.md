# Life Compass 継続利用 UX 改善計画

更新日: 2026-07-27

実装状況:

- 共同世帯の権限分離、同期間隔、共有履歴、家計入力、ホーム、設定、PWAを実装済み
- Proの固定Coming soon表示を、課金開始前・機能テスト中・Pro機能の状態表示へ変更済み
- ロジック105件、Worker API 30件、PC・スマホE2E 54件、本番ビルド、実画面確認に成功
- 本番再検証、深いセキュリティ確認、最大件数時の性能確認、一般課金は未実施

## 1. 目的

Life Compass を、初回入力だけでなく、家族で継続的に家計・目標・ライフイベントを見直せるライフプランナーへ整える。

この改善では、次を維持する。

- 投資助言サービスにしない
- 無料版を実用的に保ち、Pro は共同世帯・比較・見直しを中心に十分な価値を持たせる
- 既存の計算ロジックと保存済みデータを壊さない
- 通常の家計データと共有パスワードを平文でサーバーへ送らない
- 共同世帯の暗号化、競合検知、復旧用コピー、権限失効を維持する

## 2. 優先順位

1. 共同利用者の世帯内 Pro 権限を画面へ正しく反映する
2. 共有履歴を利用者向けの日時表示へ変更し、自動同期の負荷を抑える
3. 家計入力を「世帯全体で入力」と「家族ごとに入力」へ再構成する
4. ダッシュボードを継続利用時の確認事項中心へ並べ替える
5. 設定、共同世帯、バックアップ、使い方の導線を整理する
6. PWA のインストール導線と端末移行時の案内を追加する
7. Pro 機能を本番利用の一連の流れで検証し、固定の Coming soon 表示を契約状態別表示へ変更する
8. セキュリティ、保守性、性能、Free/Pro 境界を最終確認してから課金を公開する

## 3. 共同世帯の権限

- 個人の契約権限と、共同世帯内で owner 契約から継承する権限を分ける
- 自動同期を有効にした共同プランでのみ、共同利用者へ世帯内 Pro 機能を適用する
- 共同利用者本人の個人用プランや個人クラウドバックアップへ Pro 権限を波及させない
- owner 契約失効、membership 解除、退出、読み取り専用化を直ちに反映する
- owner 限定の招待、参加解除、鍵更新、世帯削除は維持する

## 4. 家計入力

画面上の「基本方式」「詳細方式」を、次の利用者向け表現へ変更する。

### 世帯全体で入力

- 世帯全体の月収、ボーナス、副収入、固定費、変動費、年間特別支出をまとめて入力する
- 無料版でも利用できる
- 現在の基本収支と時期別変更を維持する

### 家族ごとに入力

- 登録済みの本人、配偶者、子ども、親と「世帯共通」を選んで入力する
- 収入は対象者、住居費や光熱費は世帯共通、教育費などは対象の家族へ紐付けられる
- 同じ固定項目を全員へ複製せず、必要な収入・支出だけを追加する
- 初期状態は「今から継続」とし、開始年・終了年を通常画面へ常時表示しない
- 必要な場合だけ「将来変わる予定」を開き、期間を設定する
- 保存形式の `startYear` と `endYear`、年次計算、最大件数は維持する
- 方式を切り替えても反対側の入力データは削除しない

## 5. 共有履歴

- revision 番号は暗号化 AAD と競合検知の内部値として維持する
- 利用者向け画面では「版1」「版5」などの番号を主要表示にしない
- 「現在の共有データ」と、折りたたんだ「困ったときの復元」を分ける
- 復元候補は作成日時を中心に表示する
- 現在版を含めて最新10件まで保持し、古いものは自動削除すると明記する
- 10件超過分の削除失敗は、次回保存だけでなく定期処理でも再試行する
- 個別削除は初期実装に含めず、必要性を確認してから owner 限定の一括整理を検討する

## 6. 自動同期

- ブラウザ内保存は入力直後に行う
- 共同世帯への暗号化保存は、最後の変更から20秒後にまとめて行う
- 画面表示中の他端末確認は60秒間隔とする
- 画面復帰、オンライン復帰、「今すぐ同期」は直ちに確認する
- 変更内容のダイジェストが同じ場合はR2へ保存しない
- アプリが非表示の間は定期確認しない
- 将来必要になった場合は、共同世帯全体ではなく revision と key epoch だけを返す軽量確認 API を検討する
- 常時接続方式は導入せず、Cloudflare の通信・D1・R2負荷を抑える

## 7. ダッシュボード

継続利用時は次の順で表示する。

1. 現在の家計、純資産、生活防衛資金、将来見通し
2. 今日・今月の確認事項
3. 近いライフイベントと目標
4. 予算と実績の差
5. 入力不足や見直し候補

サンプルと入力手順は最上部へ常時表示せず、次の扱いにする。

- サンプル利用中は小さな通知帯だけ表示する
- 入力手順は折りたたむか、端末ごとに閉じた状態を保持する
- 詳細な作り方は設定内の「使い方」へ置く

## 8. 設定とデータ

設定を次の区分へ整理する。

1. アカウント・共同世帯
2. 表示・通知
3. バックアップ・復元
4. 使い方

- 「データ管理」は「バックアップ・復元」へ改名する
- 長い1ページへ統合せず、タブまたはページ内メニューで分ける
- 既存のJSON、暗号化バックアップ、復旧用コピー、初期化機能を再利用する
- 正常な同期状態は控えめに表示し、オフライン、競合、エラーだけを強調する

## 9. PWA

- Manifest、Service Worker、APIをキャッシュしない現在の境界を維持する
- 192px、512px、Apple用アイコンを用意する
- 対応ブラウザでは利用者が押す「アプリとしてインストール」を表示する
- iPhoneでは「共有からホーム画面に追加」の手順を案内する
- インストール済みの場合は案内を表示しない
- iPhoneのホーム画面アプリが別の保存領域になる場合に備え、共同世帯同期またはJSON復元の手順を案内する
- 初回表示直後の強制的な案内は行わない

## 10. Pro 課金前の受入条件

- 共同利用者が対象の世帯内 Pro 編集を行え、owner 側へ同期される
- 個人用プランへ世帯内 Pro が漏れない
- 診断、見直し案、編集、比較、採用、レビュー、復元が再読み込みと共有同期後も成立する
- 老後、固定費、積立・取り崩しのばらつき試算を境界値で確認する
- 最大20見直しプラン、多数イベント、詳細収支でもスマホで実用速度を維持する
- Free への降格、owner 契約失効、退出、解除でデータを消さず権限だけを閉じる
- PCとスマホで主要導線、PWA、バックアップ、復元、オフライン復帰を確認する
- 全体のセキュリティと保守性を確認し、重大な未解決事項がない
- 以上を満たした後だけ課金状態別表示とSquare連携を一般公開する
