# Life Compass リリース前チェックリスト

## 1. UI / 表示

- PCでダッシュボード、家計入力、資産入力、目標管理、年表、シミュレーション、老後プラン、データ管理、設定、法務ページが崩れないこと
- スマホ幅でもナビゲーション、入力フォーム、目標管理、年表、グラフ詳細、データ管理が操作できること
- 目標管理はスマホでも作成・編集・削除できること
- グラフは全点に常時ラベルを出さず、タップした年の詳細だけを表示すること
- 老後プランは表だけでなく、年齢ごとの年末資産をグラフで確認できること
- 数値入力は空欄から入力し直しても先頭に不要な `0` が残らないこと
- 予算・実績は日別家計簿ではなく、カテゴリ別の月次予算、実績、差額として確認できること

## 2. 計算ロジック

- 家計: 月収、副業収入、ボーナス、固定費、変動費、年間特別支出から月間生活費、毎月貯蓄額、貯蓄率を計算すること
- 予算・実績: 頻度ごとに月平均と年間予算を換算し、選択月の実績との差額を計算すること
- 予算・実績: 家計入力へ反映した場合、毎月固定は固定費、毎月変動は変動費、不定期・年1回は年間特別支出になり、1回だけの支出は年表イベントで扱うこと
- 資産: 現金 + 投資資産 + その他資産 - 負債 = 純資産になること
- 生活防衛資金: 働き方、家族構成、住宅ローン条件から6〜12ヶ月の目安を出すこと
- 年表: 支出イベントは差し引き、収入・資産増イベントは加算し、記録のみは試算に反映しないこと
- 目標: 1回限りの目標は達成済み額と毎月まわす額から達成目安を出すこと
- 継続目標: 頻度ごとの年間必要額と月あたり目安を表示すること
- 取り崩し試算: 期間ごとの月収入、月生活費、年間特別支出を反映し、FIREやセミリタイアのような老後以外の取り崩しも確認できること
- 老後生活プラン: 年金等、国民健康保険、介護保険、税金の概算入力を反映して年間取り崩し額を計算すること
- 老後生活プラン: 退職時点の試算資産に退職金・一時金を加え、年齢ごとの年末資産と資産寿命を表示すること
- ばらつき試算: 積立、取り崩し、老後生活プランで下位、中央値、上位の範囲と資産が尽きるケース割合を表示すること

## 3. データ管理

- 入力内容はブラウザ内保存で保持されること
- JSONエクスポートにプロフィール、家計、予算・実績、資産、目標、年表、メモ、シミュレーション条件、老後生活プランが含まれること
- JSONインポートでLife Compass形式以外を拒否すること
- 初期化は確認ダイアログを挟むこと
- 端末変更やブラウザ削除時はJSONバックアップが必要であることを画面上で説明すること

## 4. 表記 / 法務

- 通常画面で不安を煽る表現を使わないこと
- 個別の金融商品、銘柄、保険商品、暗号資産を推奨しないこと
- `投資助言`、`最適化`、`おすすめ商品`、`高収益保証` のような表現を機能訴求として使わないこと
- シミュレーション結果は `前提条件に基づく試算`、`見通し`、`参考情報` として表現すること
- 国民健康保険、介護保険、税金、年金の表示は制度上の正確な助言や正式計算ではなく、入力条件に基づく概算であることを明記すること
- ばらつき試算は将来予測ではなく、利回りが一定ではない場合の参考情報として表現すること
- 通常の取り崩し試算は老後生活プランと混同しないよう、期間別の収入・生活費による参考試算として表現すること
- 利用規約、プライバシーポリシー、特定商取引法に基づく表記、免責事項の雛形があること

## 5. Pro追加前の境界

- 無料版は1つのライフプランを作成・保存・見返し・修正できること
- Pro予定機能はComing soonとして表示し、初期版では課金処理を実装しないこと
- Pro予定機能は複数シナリオ比較、ライフプラン診断、世帯イベント管理、予算・実績レビュー、固定費見直しインパクト、見直し履歴、詳細積立、取り崩し、退職後設計を中心にすること
- データ保存はブラウザ内保存とJSONバックアップであることを画面上で明示すること
- 課金を追加する場合は、価格、解約方法、返金条件を画面上で明示すること
